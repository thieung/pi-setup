# Local / experimental extensions

Put extension directories or symlinks here when testing unpublished Pi extensions.

`pi-dev` includes this directory as an overlay; `pi` does not.

For extensions from https://github.com/luongnv89/pi-extensions that are published to npm,
prefer adding `npm:<package>` to the profile manifest. For extensions that are not published,
clone or symlink them here and use `pi-dev`.
