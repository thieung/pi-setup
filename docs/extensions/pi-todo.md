# @99percentpeople/pi-todo

Pinned in `pi` as:

```text
npm:@99percentpeople/pi-todo@1.2.8
```

## Role

Minimal atomic todo list: items are removed by omission, state survives compaction, supports dependencies, and shows a read-only widget.

## Why it is in pi

Small, deterministic, and useful on long tasks where compaction would otherwise lose the plan.

## Guardrails

- Todo state is session state; it is not portable configuration and must not be committed.

## Provenance

Recommended from `mrgoonie/zuey-pi-setup` and `luongnv89/pi-extensions`. Version pinned from the npm registry on 2026-09-30.
