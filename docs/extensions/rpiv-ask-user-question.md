## Role

Lets the agent ask you multiple-choice questionnaires instead of guessing when a requirement is ambiguous.

## Why it is in pi

Interaction-only. It adds no background behavior, so it is safe for daily work.

## Guardrails

- Answers are part of the session transcript; do not type secrets into questionnaires.
