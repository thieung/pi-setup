# timestamp-pi

Pinned in `pi-dev` as:


## Role

Message timestamps plus a prompt-cache TTL countdown.

## Why it is in pi-dev

UI/observability companion to `statusline-pi` by the same author. Useful when tuning prompt-cache behavior.

## Guardrails

- Both it and `statusline-pi` draw UI; if the footer looks cluttered, disable one.
